# Terminal AI Snake (终端自动寻路贪吃蛇)

**项目简介：** 一个基于 C++ 开发的自动寻路贪吃蛇小游戏。

### 🛠️ 技术栈
* **语言:** C++
* **编程思想:** 面向对象编程 (OOP)
* **核心算法:** 广度优先搜索 (BFS)

### ✨ 核心亮点
1.  **架构解耦：** 摒弃了单文件面向过程的写法，使用了面向对象的设计模式，将地图 (Map)、蛇 (Snake) 和游戏控制 (Game) 模块完全分离。
2.  **AI 寻路：** 抛弃了传统的手动控制，通过 BFS 算法计算曼哈顿距离，实现了寻找食物的最短路径实时规划。

### 🚀 如何运行
直接在支持 C++11 及以上的编译器中运行 `main.cpp` 即可。
